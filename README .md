##Коротко о проекте

Проект представляет собой рекламную веб-страницу вымышленных курсов программирования на Pascal, оформленную в стиле эпохи Turbo Pascal - времени, когда персональные компьютеры только становились массовыми, а программирование было доступно не только профессионалам, но и любителям. Страница передаёт атмосферу начала 1980-х годов: чёрный экран DOS, дискеты, компьютерные журналы с листингами программ и первые шаги в профессию программиста.
